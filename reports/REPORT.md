# VancoDose — model development report

Generated by `python -m vanco.report`. All numbers come from `reports/*.csv|json`.

## 1. Data

* Three tables: 394 patients → 1182 regimens (3 per patient: standard, loading, auc_targeted) → 1,022,430 concentration rows (865 five-minute points over 72 h per regimen).
* Patients with SCr > 3.5 mg/dL removed before all analyses (6 patients).
* No missing values (0), no duplicate keys, full referential integrity.
* Exact identities found: AUC24 = daily dose ÷ true clearance (max relative error 3.7e-05); AUC/MIC = AUC24 ÷ MIC; CrCL = Cockcroft–Gault on total body weight; obesity flag = BMI ≥ 30.
* Assay noise in `conc_measured_mg_L`: combined ≈1.5 mg/L additive + ≈15% proportional, independent between samples.
* Split: existing patient-grouped split kept; development = 314 patients (grouped 5-fold CV), test = 80 patients used once at the end.

### Leakage removed
The following can never be model inputs: seed, true_CL_L_h, true_CL_residual_L_h, true_CL_dialysis_L_h, true_Vd1_L, true_Vd2_L, true_Q_L_h, true_ke_per_h, true_alpha_per_h, true_beta_per_h, true_tHalf_beta_h, true_AUC24_ss_mg_h_L, AUC24_true_mg_h_L, AUC24_trapezoidal_mg_h_L, AUC_MIC_ratio, trough_ss_mg_L, peak_ss_mg_L, ss_reached, conc_true_mg_L, auc_targeted regimen dose. The auc_targeted regimen's dose is itself leakage: its log-dose correlates 0.87 with the latent clearance (vs 0.40 for standard dosing).

## 6. Accuracy goal (MAE < 90, RMSE < 100 mg·h/L)

The goal is met for the regimens the tool recommends after levels, and the MAE part is met for regimens aimed at the target range. It is not met across all regimens, whose simulated exposure reaches several thousand mg·h/L. Why:

AUC24 = daily dose ÷ CL exactly, so the error is the error in clearance multiplied by the exposure. Covariates leave ~26% (log-SD) of clearance unexplained — this is the simulator's random between-patient variability and no algorithm can predict it (all eight algorithms converge to the same error; linear models are best because the simulator's covariate model is log-linear). Two noisy levels within the first 72 h reduce this to ~15–20%; in a supplementary development check, even hourly sampling over 72 h only reached ~13–16%, because the ~15% assay noise and the slow peripheral compartment make clearance hard to separate from distribution within 72 h. With a cohort median AUC24 near 800 mg·h/L under standard dosing, an absolute MAE < 90 would need roughly 11% clearance error across all regimens. The goal is approached for exposures near the therapeutic range, which is where dosing decisions are made.
